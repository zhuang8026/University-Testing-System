# 第2.1章：IP與Subnet概念

1. 當 Subnet Mask 寫成 /18 時，即表示在二進位中有幾個 1？
(A) 16 (B) 24 (C) 32 (D) 18
答案：(D)
2. 下列哪一個數字，不會出現在十進位的子網路遮罩中？
(A) 252 (B) 254 (C) 253 (D) 255
答案：(C)
3. IPv4 位址主要有幾個位元所組成？
(A) 32 位元 (B) 64 位元 (C) 128 位元 (D) 16 位元
答案：(A)
4. 192.168.5.10/28 中，其中 28 代表何者？
(A) VLAN ID (B) DNS 第一組 (C) 子網路遮罩為 255.255.255.240 (D) 預設閘道為 192.168.5.28
答案：(C)
5. 子網路遮罩 /22 相當於？
(A) 255.255.252.0 (B) 255.255.254.0 (C) 255.255.253.0 (D) 255.255.255.0
答案：(A)
6. 設定 IP 時，下列哪一項不是必填？
(A) 預設閘道 (B) IP 位址 (C) MAC 實體位址 (D) 子網路遮罩
答案：(C)
7. 在 Windows 系統中，查詢本機完整 IP 配置指令為？
(A) ping /all (B) netstat -r (C) ifconfig -a (D) ipconfig /all
答案：(D)
8. SOHO 網路常用哪一段做為內部私有 IP？
(A) 192.168.0.0/24 (B) 172.16.0.0/16 (C) 10.0.0.0/8 (D) 172.31.0.0/16
答案：(A)
9. 私有 Class C 位址是哪一段？
(A) 172.32.0.0/255.255.0.0 (B) 127.0.0.0/255.255.255.0 (C) 10.0.0.0/255.0.0.0 (D) 192.168.0.0/255.255.255.0
答案：(D)
10. IP 127.0.0.1 在 TCP/IP 中代表何者？
(A) 本機迴路位址 (B) 無線 AP 位址 (C) 公用 DNS 伺服器 (D) 私有網路預設閘道
答案：(A)
11. 下列哪一組為合法的 IPv4 位址？
(A) 192.168.0.256 (B) 114.34.72.8 (C) 127.0.0.1 (D) 256.100.50.1
答案：(B)
12. 某一 IP/Subnet Mask 為 192.168.100.128/255.255.255.224，請問這個 IP 可以當作什麼用途？
(A) 路由器 (B) 廣播位址 (C) 代表整個網路 (D) 電腦主機
答案：(C)
13. 若一部電腦的 IP 位址為 163.13.238.243，網路遮罩為 255.255.255.240，則其所在網段的網路位址為？
(A) 163.13.238.255 (B) 163.13.238.128 (C) 163.13.238.240 (D) 163.13.238.0
答案：(C)
14. 當 IP 為 192.168.1.10/24 時，其網路位址是？
(A) 192.168.1.255 (B) 192.168.0.0 (C) 192.168.1.1 (D) 192.168.1.0
答案：(D)
15. 當 IP 為 10.0.5.130/26 時，其廣播位址是？
(A) 10.0.5.255 (B) 10.0.5.127 (C) 10.0.5.191 (D) 10.0.5.128
答案：(C)
16. 若 IP 為 10.1.2.3，子網路遮罩為 255.0.0.0，該主機所屬網路為？
(A) 0.0.0.0 (B) 10.1.2.0 (C) 10.0.0.0 (D) 10.1.0.0
答案：(C)
17. 若 IP 為 10.1.2.3，子網路遮罩為 255.255.0.0，該主機所屬網路為？
(A) 0.0.0.0 (B) 10.1.2.0 (C) 10.0.0.0 (D) 10.1.0.0
答案：(D)
18. 當 IP 網段為 10.0.0.0/8 時，其第一個可用主機 IP 位址是？
(A) 10.0.0.1 (B) 10.0.0.0 (C) 10.255.255.254 (D) 10.0.0.255
答案：(A)
19. 若以 255.255.255.192 做為子網路遮罩來區隔網路，則每個子網域最多能有幾個 IP 位址？
(A) 32 (B) 256 (C) 64 (D) 128
答案：(C)
20. 子網路切割規劃中，如果使用 255.255.255.128 網路遮罩來區隔 C 級網段，每個子網路最多能分配幾個 IP 位址？
(A) 64 個 (B) 128 個 (C) 512 個 (D) 256 個
答案：(B)
21. 當 Subnet Mask 為 255.255.255.248 時，此子網每個子網路的 IP 數量為？
(A) 32 (B) 16 (C) 24 (D) 8
答案：(D)
22. 192.168.10.0/27 可提供多少個 IP 位址在網路主機的設備上？
(A) 64 (B) 30 (C) 16 (D) 32
答案：(B)
23. 若子網路切割規劃中，如果使用連續 23 個 1 當作二進位網路遮罩，那每個子網路最多能分配幾個 IP 位址？
(A) 64 個 (B) 512 個 (C) 256 個 (D) 128 個
答案：(B)
24. 若每個子網域期望能有 600 台電腦可以同時上網，則子網路遮罩可設定為？
(A) 255.255.252.0 (B) 255.255.255.128 (C) 255.255.254.0 (D) 255.255.255.0
答案：(A)
25. 若要將 Class C 網路細分為 8 個子網，子網路遮罩應為？
(A) /26 (B) /25 (C) /28 (D) /27
答案：(D)
26. 在 192.168.32.0 的區域網路上做子網路切割，假設該子網路可用的 IP 位址數量約為 30 個，下列哪些表示方式為正確？
(A) 192.168.32.0/255.255.255.248 (B) 192.168.32.0/255.255.255.240 (C) 192.168.32.0/28 (D) 192.168.32.0/27
答案：(D)
27. 一個私有 B 級網路可拆分成多少個 /24 子網？
(A) 256 (B) 128 (C) 1024 (D) 512
答案：(A)
28. 合併兩個 C 級網路 192.168.2.0/24 和 192.168.3.0/24 為 /23 後，網路範圍為？
(A) 192.168.5.0 ~ 192.168.5.255 (B) 192.168.0.0 ~ 192.168.5.255 (C) 192.168.2.0 ~ 192.168.3.255 (D) 192.168.2.0 ~ 192.168.2.255
答案：(C)
29. 關於子網路分割的描述，何者敘述不正確？
(A) IP 的數目可自由規劃不受影響 (B) 讓不同單位使用不同子網路以方便網路管理 (C) 可減少封包傳送時出現碰撞的情況 (D) 利用子網路遮罩可以分辨不同單位所使用的 IP 位址
答案：(D)
30. DNS 正向解析是指？
(A) IP 轉區段識別 (B) 網域名稱轉 IP 位址 (C) 網域名稱轉子網路識別 (D) IP 轉網域名稱
答案：(B)
31. DNS 反向解析指的是？
(A) IP 位址到 MAC 位址 (B) IP 轉網域名稱 (C) 子網路遮罩到無類別域間路由 (D) 網域名稱到郵件地址
答案：(B)
32. TCP 協定提供何種傳輸服務？
(A) 僅廣播傳輸 (B) 無連線且不可靠 (C) 連線導向且可靠傳輸 (D) 僅多播傳輸
答案：(C)
33. 下列何者非 UDP 的特性？
(A) 資料無重傳保證 (B) 適用影音串流 (C) 無連線 (D) 提供可靠連線
答案：(D)
34. OSI 模型第 3 層為何？
(A) 資料鏈路層 (B) 網路層 (C) 應用層 (D) 傳輸層
答案：(B)
